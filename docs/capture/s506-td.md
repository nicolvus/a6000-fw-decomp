# S506 — módulo `[TD]` (codec transcode/decode, línea general)

## Alcance

Decodificación del módulo `[TD]` (prefijo `[CodecSeq][TD]`) del `av-cam.bin` A6000
fw3.21, comparado con A7S fw3.20 y A6300 fw2.01.

## VERIFICADO

- **Volumen de trazas:** A6000 = 73 cadenas `[TD]`; A7S = 73; A6300 = 84.
  Fuente: `strings | grep -c '\[TD\]'`.
- **Inventario REA:** 73 cadenas (`analysis/s506_td/td_strings.json`).
- **Referencias de código:** 71 xrefs (`analysis/s506_td/td_xrefs.json`); 12 funciones
  contenedoras resueltas (`analysis/s506_td/td_functions.json`).
- **Subsistemas inferidos (VERIFICADO por texto):** secuencia de códec (open/start/next
  frame/stop/close, ACK/COMP/ERROR) para encode y decode, gestión de pines YC/AUDIO
  (connect/disconnect/request), envío de mensajes (MSGID_PIN_CONNECT*), y transmisión
  interna (ENC_STOP_BY_INTERNAL_CMP, DEC_STREAM END, DEC_Frame display/hide).
- **Comparación:** idéntico A6000/A7S (73); A6300 tiene 84 (11 más). Ver
  `analysis/s506_td/td_compare.json`.

## INFERENCIA

- `[TD]` = módulo de **transcodificación/decodificación** de vídeo/audio (transcode
  device) dentro de `CodecSeq`; no relacionado con obturador electrónico.
