# Comparación inicial

[VERIFICADO documental] Sony ILCE-6300 ofrece Toma silenciosa para fotografía: https://helpguide.sony.net/ilc/1540/v1/es/contents/TP0000825735.html . Sony ILCE-6000 documenta EFCS: https://helpguide.sony.net/mig/Z001924611/EN/contents/TP0000226634.html .

Esto selecciona la A6300 como candidata comparativa, sin establecer sensor idéntico ni compatibilidad de firmware. No se descargó firmware A6300 ni se compararon hashes o grafos entre modelos. Tampoco se extrapolan sus limitaciones de flash, bits o resolución a la A6000.

Siguiente prueba: adquirir actualizador oficial del comparador, verificar versión y extracción; buscar la ruta SilentShutter y sus controladores, después comparar funciones con límites explícitos de hardware y arquitectura. Copiar bytes o habilitar un menú no está justificado.

OpenMemories-Tweak habilita ajustes y depuración, pero su documentación/código revisado no aporta una secuencia de cortina electrónica. PMCA documenta ejecución de código temporal en modo actualizador: denominarlo únicamente lectura es incompleto aunque el posterior volcado use pull. No se ejecutó ese procedimiento aquí.
